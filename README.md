# Web開発学習ダッシュボード

Webアプリケーション開発の授業全体をもとにした総合作品です。

## 使用技術
- HTML
- CSS
- JavaScript
- LocalStorage
- GitHub REST API

## 主な機能
- 全15回の授業内容一覧
- Linuxコマンド検索
- CRUD型の学習TODO
- TODOのLocalStorage保存
- GitHub公開APIからJSONデータ取得
- 授業内容の理解度チェック

## 授業内容との対応
Linux、HTTP/API、Git/GitHub、Docker、Node.js、JavaScriptの配列操作、
CRUD、モジュール化、テスト、Bot開発などの学習内容を作品内で整理・応用しています。
